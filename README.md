API (Application Programming Interface) — это интерфейс программирования приложений.
Проще говоря, это набор правил и инструментов, с помощью которых одна программа может взаимодействовать с другой. API позволяет разработчикам использовать функции и данные другой программы, не вникая в её внутреннюю реализацию.

REST — это архитектурный стиль (или подход) к созданию API.
	•	Он использует существующий протокол — HTTP (а не изобретает свой).
	•	Поэтому REST API — это интерфейс, который построен на базе HTTP, но сам по себе протоколом не является.

Можно сравнить так:

HTTP — это шоссе, по которому едут данные.
REST — это правила, по которым едут машины на этом шоссе (например, “на зелёный — ехать, на красный — стоять”).
